## Overview

This repository demonstrates an automated architecture for conducting PRISMA-compliant systematic reviews and meta-analyses. It scaffolds the steps of a PRISMA flow using Python.

## How to Run

To execute the scaffold and observe the pipeline architecture:

```bash
python ingest_literature.py
python screen_literature.py
python extract_taxonomy_matrix.py
python synthesize_statistics.py
python generate_manuscript.py
```
